# MyChess64 – Chess Basics for Kids

A single-file, kid-friendly chess learning web app (no build step, no dependencies).

## Topics
1. Board Setup · 2. Identify Pieces · 3. Learn Coordinates · 4. Find the Square
5. Name the Square · 6. Piece Points · 7. Piece Movement · 8. Castling (FIDE rules)

## Features
- Lichess-style board and standard piece set
- Live score: Attempts / Correct / Incorrect / Streak / Score %
- Sound effects, confetti and flying chess pieces
- Responsive: board stays pinned, lessons scroll (phone, tablet, desktop)

## Run locally
Open `index.html` in any browser.

## Publish with GitHub Pages
1. Create a repository and upload `index.html` and `README.md` to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://<username>.github.io/<repository>/`.

Fonts (Fredoka, Nunito) load from Google Fonts; everything else, including the logo, is embedded in `index.html`.
