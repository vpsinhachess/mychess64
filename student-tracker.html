Enter a student's Lichess and/or Chess.com username to see their ratings, activity and progress.

Fill at least one username. Leave the other empty if the student does not use it.
The puzzle dashboard needs the student's own Lichess token, because Lichess shares it only with its owner. Create one here (tick only "Read puzzle activity"). It is stored only in this browser and sent only to lichess.org.
Period progress works instantly for past dates, using each site's own history. Lichess is exact; Chess.com is approximate.

Progress compares today with a snapshot from about 7 days earlier. Snapshots are saved in this browser, so open this file in the same browser each week. Chess.com puzzle rating is the highest tactics rating, because the public API does not share the current one.
