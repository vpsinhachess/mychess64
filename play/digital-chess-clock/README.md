# MyChess64 Chess Clock

Open `index.html` in any browser (no build step).

```
index.html
css/   base.css (tokens, layout) · clock.css (panels, digits, controls) · sheet.css (light time-control sheet)
js/    state.js · ui.js · device.js · engine.js · sheet.js · main.js   (loaded in this order)
assets/wK.svg, bK.svg   cburnett king pieces (Colin M.L. Burnett, Wikimedia Commons; GPL / BSD / GFDL)
```
Shortcuts: Space = press clock, P = pause, R = reset, M = settings, Esc = close.
