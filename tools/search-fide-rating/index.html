How to use the FIDE Rating Explorer

Enter a numeric FIDE ID to see a player’s rating progress and a rating history table. The data comes from the public FIDE dataset through Lichess’s FIDE API, so figures reflect what that dataset publishes.

  1. Type the numeric FIDE ID and press Search player.
  2. Choose Standard, Rapid or Blitz, then a period: last 1, 2, 3 or 5 years, all available, or a custom range.
  3. Read the highest, lowest and rated-games figures and the rating history table.
  4. Use the links to search Chess-Results, open the official FIDE profile or open Lichess FIDE.

FIDE Rating Explorer FAQ

Where does the data come from?

From the public FIDE dataset through Lichess’s FIDE API.

Does it list a player’s games?

No. The FIDE rating-history API gives rating points, not a game-by-game list. PGNs come from tournament and game databases.

How do I find a FIDE ID?

The FIDE ID is the numeric identifier on a player’s official FIDE profile.
