Chess Class Schedule Maker

Generate every session date for a batch.

www.mychess64.com

Add holidays in the skip-dates field and those sessions are removed from the list. Your inputs are remembered on this device.

How to use the Chess Class Schedule Maker

Plan a batch in seconds. Enter the days your class meets, the start time and duration, the start date and the number of weeks, and the tool lists every session date. Add holidays to the skip-dates field to remove those sessions.

  1. Enter the Class name and the Days, for example Mon, Wed, Fri.
  2. Enter the Start time, Duration (minutes), Start date and Weeks.
  3. Add holidays in Skip dates as YYYY-MM-DD, separated by commas.
  4. Use Print, Copy results, Download CSV or Download PDF to share the schedule.

Chess Class Schedule Maker FAQ

How do I skip holidays?

Add them in the skip-dates field in YYYY-MM-DD format, separated by commas, and those sessions are removed from the list.

Can I export the schedule?

Yes. Use Download CSV or Download PDF, or Print.

Are my entries saved?

Your inputs are remembered on this device.
