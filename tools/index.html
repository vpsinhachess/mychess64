About MyChess64 chess tools

MyChess64 tools are small, focused utilities for the jobs chess players, coaches and tournament organisers do again and again: reading and cleaning PGN, checking FEN, making diagrams and GIFs, calculating ratings, planning events and running an academy.

Chess tools FAQ

Are the chess tools free?

Yes. All the tools on this page are free to use.

Do I need to install anything or sign up?

No. The tools open and run in your browser.

Is my data uploaded?

Most tools run entirely in your browser. The FIDE Rating Explorer fetches public player data for the FIDE ID you enter.

Which tool should I start with?

For games, try the PGN Viewer. For positions, the Chess Diagram Generator. For events, the Swiss Rounds Calculator and Tournament Time Planner.
